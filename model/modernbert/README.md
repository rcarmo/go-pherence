# ModernBERT

Native FP32 ModernBERT encoder used as the prerequisite for Laya. The implementation follows Transformers commit `c587bc884db2c2e31fc2b8102314656b17aa07b1`; released-model evidence pins `answerdotai/ModernBERT-large` revision `45bb4654a4d5aaff24dd11d4781fa46d39bf8c13`.

Implemented operations:

- token embedding plus pre-encoder LayerNorm;
- fused bias-free QKV and output projections;
- bidirectional full/sliding attention with padding-key masks;
- separate full/local RoPE frequencies;
- first-layer identity attention norm, later pre-norm attention;
- pre-norm GeGLU MLP and residuals;
- final LayerNorm.

`Load(modelDir)` strictly validates the released bias-free GELU checkpoint geometry. `Forward(ids, mask)` returns `[sequence,hidden]` FP32 values. `ForwardLayers` is a parity/debug API and owns every returned layer copy.

## Validation and limits

A three-layer, width-16 CPU fixture generated by `scripts/modernbert-reference.py` compares embeddings, every layer and final output against pinned Transformers. It includes full/sliding attention and padding. The released 28-layer, width-1024 checkpoint matches selected layers 0, 13, 27 and final normalization using `scripts/modernbert-released-reference.py`.

Current limitations remain explicit:

- FP32 only; the private loader transfers freshly decoded float32 tensors into the model, while public `New` copies caller data. Released loading peaks around 2.95 GiB RSS for the 1.58 GB checkpoint.
- The tokenizer wrapper and special-token validation are implemented, but pooled embedding/task heads, training/backward, packed weights and quantization are not.
- `Session.ForwardInto` is the optimized API: tiny and released warm inference measure 0 B/op and 0 allocations/op. The convenience `Forward` creates a session and owned output.
- Only bias-free exact-GELU checkpoints are admitted. Other ModernBERT config variants fail rather than being approximated.
- Released Intel execution is validated. Native ARM executes the tiny full/sliding/padding fixture at about 35 µs with 0 B/op and 0 allocations/op; the 1.58 GB released model is not present on that host. Cross-compilation is not runtime evidence.
- Package statement coverage with the opt-in released-model tests is 90.7%; without the local checkpoint it is 83.8%.

This is an encoder milestone, not yet the full Laya implementation.
