# Simple-JEV-style scoring primitives

`model/simplejev` is a separately authored, model-free MIT component. It accepts ordered, distinct label-token IDs and finite F32 logits, then returns a distribution over only those labels. `Choice` breaks exact logit ties by input order. `Ordinal` uses caller-specified finite values; it does not infer score levels or a Noul scale from a prompt.

`DecodeRequest` admits a separate strict JSON envelope with one state and 1–256 ordered choice/ordinal questions, 2–50 labels each, an explicit 1 MiB body cap, and decoded UTF-8 byte limits on text fields. Object keys must match lowercase field names exactly and cannot repeat; blank/invisible-only text and IDs containing whitespace or controls are rejected. This schema is not the upstream wire format. `Evaluate` accepts an injected provider of ordered label-token logits and returns complete, owned answers only if every row validates; ordinal levels are zero-based label positions. `TokenLogitAdapter` joins an injected renderer, tokenizer and selected-logit backend. It requires an explicit public-ID/model-text pair for every label, verifies that each model-text label adds one distinct token at the actual prompt boundary, and copies mutable tokenizer/provider buffers before scoring. `DecodeTextStateRequest` separately admits a bounded upstream-shaped **text-state subset**: ordered Choice/Score/Noul questions, nullable text instructions and descriptions, and explicit rejection of messages, structured content and media. Its pinned validation fixture comes from upstream Pydantic without running a model. This package has no shipped prompt template, concrete model backend or HTTP endpoint. A separate independent upstream fixture checks model-free choice/score probabilities and the nine-bin Noul numerical mapping. It does not qualify upstream request, prompt, tokenizer or model parity, text generation, calibration or model quality. Do not mix its semantics with the existing `model/jevlike` scoring head or reuse the spent Jev bake-off cohorts for selection. The [upstream review](../../docs/validation/simple-jev-upstream-review-20260920.md) records the licensing change and remaining gates.
