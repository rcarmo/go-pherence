# MoJev metadata boundary

`ReadConfig` accepts a pinned, metadata-only `MoLeMo-Lab/mojev` PackedScorer config. It validates the 24-layer Qwen3.5-0.8B hybrid text stack (18 linear and six full-attention layers), nested vision metadata, rank-512 readout, 16,384-token context setting, and 64-option `answer` schema. The Qwen3.5 projection shapes come from `loader/config/qwen35_shapes.go`. A successful parse always returns `RuntimeReady=false`.

The repository-owned config fixture is `testdata/mojev_config.json`, from Hugging Face revision `0c8695b6252f4205907433d4e196a94f032e60c3` (5,935 bytes; SHA-256 `1b3fb0dd8ae5a1e334b31bae1cfb2e8212231bd549884819304f29334313f4c9`). The source assessment uses MIT `MoLeMo-Lab/mojev@a74d58cd19ec573e83e8e27f9fecd837b8d830fb`; `mojev/modeling.py` has SHA-256 `a8e93f62d92c6748c5d001fef4f9516d6a74b10158d7265f53bab13f1091d458`. No tensor payload or inference output is in this fixture. The model page lists `model.safetensors` as 1,710,234,304 bytes; it has **not** been downloaded or read here.

The upstream scorer uses a three-level tree mask: state, isolated questions and isolated candidates. Its encoder runs in BF16 and its two projections and LayerNorm head in F32. The rank-512 readout combines state and question projections with pooled candidate keys, then masks absent options. Existing Go Qwen3.5 support provides text backbone shapes and state helpers, but does not supply this scorer, multimodal packing, the tree mask or an independently checked readout. Metadata acceptance is not model readiness.

A five-sample **cold config parse**, measured on an i7-12700 with six visible CPUs, Go 1.26.3, Linux amd64 and `GOMAXPROCS=2`, yielded 48,138–52,375 ns/op, 18,353–18,356 B/op and 217 allocs/op (`-benchtime=200x -count=5`). An exhaustive allocation profile attributed most bytes to `io.ReadAll` and JSON decoding. Config parsing occurs once per load; no hot-path optimisation was retained or latency improvement claimed. CPU inference, released logits/probabilities, Choice/Noul/Score quality, image input, ownership, concurrent admission and service wiring require separate fixtures and approval.
