# cmd/models — model inspection & coverage

Format/inspection utilities that work across model families (GGUF, safetensors).

| Command | Purpose |
|---|---|
| `ggufinspect` | Dump GGUF metadata / tensor layout |
| `ggufsmoke` | GGUF load smoke test |
| `shapecheck` | Verify tensor shapes against expectations |
| `embcheck` | Embedding sanity check |
| `modelcoverage` | Op/coverage report for a model |
| `lfm2inspect` | Inspect LFM2 models |
| `gemma4mtpsmoke` | Gemma MTP smoke test |
