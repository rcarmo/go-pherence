# cmd/image — image & 3D generation tools

| Command | Purpose |
|---|---|
| `ideogram4gen` | Ideogram v4 image generation |
| `qwenimage21` | Strict CPU-only Qwen Image 2.1 generation via an audited `stable-diffusion.cpp` `sd-cli`, plus native weight inspection |
| `ideogram4inspect` | Inspect Ideogram v4 model |
| `ideogram4vaesmoke` | Ideogram v4 VAE smoke test |
| `zimageinspect` | Inspect Z-image model |
| `hy3dinspect` | Inspect Hunyuan3D model |
