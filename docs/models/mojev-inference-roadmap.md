# MoJev inference roadmap

The native MoJev slices validate pinned checkpoint metadata and a synthetic tree mask. `model/mojev` accepts a 5,935-byte config fixture from [`MoLeMo-Lab/mojev`](https://huggingface.co/MoLeMo-Lab/mojev) at revision `0c8695b6252f4205907433d4e196a94f032e60c3` (MIT; SHA-256 `1b3fb0dd8ae5a1e334b31bae1cfb2e8212231bd549884819304f29334313f4c9`). It does not read the 1,710,234,304-byte `model.safetensors`. The independently inspected [MIT source](https://github.com/MoLeMo-Lab/mojev) is pinned at `a74d58cd19ec573e83e8e27f9fecd837b8d830fb`; `mojev/modeling.py` hashes to `a8e93f62d92c6748c5d001fef4f9516d6a74b10158d7265f53bab13f1091d458`.

The checkpoint declares `PackedScorer`: a Qwen3.5-0.8B encoder with 24 text layers (three linear attention followed by one full attention, repeated six times), width 1,024, BF16 encoder weights, a rank-512 F32 projection and LayerNorm head, and a nested Qwen3.5 vision config. The saved schema declares one `answer` choice field with 64 slots. The source builds a three-level additive attention tree to isolate sibling questions and candidates; candidate scores combine pooled state/question query and candidate key and mask absent options. Existing `loader/config/qwen35_shapes.go` admits the text projection geometry. `model/mojev.TreeMask` checks a separate, model-free single-row allowed-position matrix against two pinned upstream cases, including a padded row. It is bounded at 4,096 positions, 256 questions and 64 candidates per question, and is not connected to attention. The scorer's additive mask, packed-mask interaction, pooling, head and vision input are unimplemented. `RuntimeReady=false`.

## Separate gates

1. Obtain explicit approval and a disk/memory budget for checkpoint payload and independent Transformers execution. `/srv` had about 5.8 GB free during the metadata review; do not fetch the 1.71 GB checkpoint into the repository or consume space implicitly. Pin filenames, byte counts and SHA-256 before loading.
2. Capture untouched independent released-model fixtures for tokenizer/processor, packed state/question/candidate spans, the additive tree mask with packed-mask interaction, option mask, hidden rows, BF16/F32 head logits and public Choice/Noul/Score probabilities. Include permuted candidates, hostile delimiters, missing options, mixed text/image inputs and rejection cases.
3. Implement a bounded native scorer with request-owned scratch. Match released logits and answers against those fixtures before profiling or claiming inference. Qualify peak/retained memory, concurrency, ARM64/RISC-V execution and service wiring separately.
4. Evaluate quality and calibration on a fresh held-out cohort. Do not reuse the frozen Jev bake-off or present published upstream metrics as local results.

MoJev's packed readout differs from Simple-JEV's selected next-token label logits and Kev's pointer head. Keep all three adapters separate.
