# Needle 3 packed archive parser boundary

`loader/needle.LoadArchivePacked` and `ParseArchivePacked` validate CQ records without retaining whole-matrix F32 data. They keep owned CQ blobs, decode and check every 128-element group for invalid norms, ternary crumbs and non-finite reconstructed values, and continue to decode non-CQ records normally. `DecodeCQRecord` allows a model consumer with no packed path to reconstruct a selected CQ record after parsing. The existing `LoadArchive` and `ParseArchive` remain unchanged for decoded callers.

`model/needle.LoadArchivePacked` maps a Needle3 archive directly into the compact inference view. It constructs CQ matrices for complete embedding and layered projection sites without keeping decoded F32 copies, then reconstructs CQ auxiliary-head projections as decoded F32 because `probeHead` consumes them. Partial layered CQ coverage, mixed decoded/packed tensors and Needle2 archives fail. The original `model/needle.LoadArchive` and `newModel` remain the decoded defaults.

The tiny `.cact` fixture's packed records have nil `Data`; selected reconstructed records match the standard parser's F32 records. Full-sequence, cached and embedding/confidence/router head outputs from the direct model match the decoded hybrid under existing test gates. Truncated archives, invalid norms and codebooks fail in both parser modes; the mapper rejects a missing packed embedding and a partial CQ layer. Focused and race tests passed ten repetitions for the parser and direct loader.

The locally pinned released `Cactus-Compute/needle3` archive (revision `b274efcb211a9eef48c9a88da4b43bd569696a39`, SHA-256 `c9d915eca282ed42d1a09b143b592adb4cc6744ffe2d294adf5cfc5548170c38`) passed one opt-in two-token full-sequence and cached comparison against the decoded hybrid path. The archive contains no auxiliary heads, so released head parity was not tested. Decoded retained tensor payloads measured by `DecodedBytes()` were 484,079,444 bytes for the decoded model and 291,796,820 for the direct model; direct packed matrices account for another 14,814,512 logical bytes. These counts exclude Go map/slice overhead and unrelated allocations. They are neither peak nor retained process RSS. A first conservative 1 GiB mapper estimate rejected the released archive at 1,750,145,904 bytes; accounting for one full expanded tensor set instead of three reduced the estimated bound and admitted the same archive. The bound is a logical construction limit, not observed peak memory.

Admission bounds file bytes, individual CQ decoded geometry, retained parser bytes and the model mapper's conservative logical restacking/copy estimate. Released-size throughput, broader prompts, cancellation/concurrency, memory sampling and native SIMD evidence are separate gates.
