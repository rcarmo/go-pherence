# Needle 3 packed archive parser boundary

`loader/needle.LoadArchivePacked` and `ParseArchivePacked` validate CQ records without retaining whole-matrix F32 data. They keep owned CQ blobs, decode and check every 128-element group for invalid norms, ternary crumbs and non-finite reconstructed values, and continue to decode non-CQ records normally. `DecodeCQRecord` allows a model consumer with no packed path to reconstruct a selected CQ record after parsing. The existing `LoadArchive` and `ParseArchive` remain unchanged for decoded callers.

`model/needle.LoadArchivePacked` maps a Needle3 archive directly into the compact inference view. It constructs CQ matrices for complete embedding and layered projection sites without keeping decoded F32 copies, then reconstructs CQ auxiliary-head projections as decoded F32 because `probeHead` consumes them. Partial layered CQ coverage, mixed decoded/packed tensors and Needle2 archives fail. The original `model/needle.LoadArchive` and `newModel` remain the decoded defaults.

The tiny `.cact` fixture's packed records have nil `Data`; selected reconstructed records match the standard parser's F32 records. Full-sequence, cached and embedding/confidence/router head outputs from the direct model match the decoded hybrid under existing test gates. Truncated archives, invalid norms and codebooks fail in both parser modes; the mapper rejects a missing packed embedding and a partial CQ layer. Focused and race tests passed ten repetitions for the parser and direct loader.

The locally pinned released `Cactus-Compute/needle3` archive (revision `b274efcb211a9eef48c9a88da4b43bd569696a39`, SHA-256 `c9d915eca282ed42d1a09b143b592adb4cc6744ffe2d294adf5cfc5548170c38`) passed an opt-in twelve-token full-sequence and cached comparison against the decoded hybrid path, including a race run. The archive contains no auxiliary heads, so released head parity was not tested. Decoded retained tensor payloads measured by `DecodedBytes()` were 484,079,444 bytes for the decoded model and 291,796,820 for the direct model; direct packed matrices account for another 14,814,512 logical bytes. These counts exclude Go map/slice overhead and unrelated allocations. They are neither peak nor retained process RSS. A first conservative 1 GiB mapper estimate rejected the released archive at 1,750,145,904 bytes; accounting for one full expanded tensor set instead of three reduced the estimated bound and admitted the same archive. The bound is a logical construction limit, not observed peak memory.

On one i7-12700 Linux host (`GOMAXPROCS=6`, GPU disabled), four fresh-process runs per mode in rotated order used the pinned released archive and five two-token cached decodes per process. `/usr/bin/time` VmHWM medians were 840,432 KiB decoded, 840,482 KiB hybrid and 381,928 KiB direct; direct minus hybrid is −458,554 KiB (about 54.6% of hybrid peak). Post-load `/proc/self/status` VmRSS medians after `debug.FreeOSMemory` were 496,146, 496,168 and 308,008 KiB. Post-warm medians were 497,200, 497,278 and 308,930 KiB. Median loader elapsed time was 1,179 ms decoded, 1,146 ms hybrid and 1,271.5 ms direct. Across 20 warmed two-token calls per mode, median decode time was 33,386 µs decoded, 50,484 µs hybrid and 50,770.5 µs direct. The direct packed path reduced observed peak and retained RSS in this bounded process comparison; it did not improve short decode speed. The probe does not test real prompt quality, sustained throughput, other hosts or non-amd64 kernels. Raw process logs: `/workspace/tmp/needle3-resource-{decoded,hybrid,direct}.log` (workspace-local, outside the repository).

Admission bounds file bytes, individual CQ decoded geometry, retained parser bytes and the model mapper's conservative logical restacking/copy estimate. Tiny-fixture eight-caller independent cached sessions, pre-cancelled step recovery and caller-output mutation pass ordinary and race repetitions. The pinned archive also reproduces the earlier twelve-token `Hello` chat-prompt continuation through the direct loader and decoded reference: `[6,38,8141,1515,4047,997,598,782,326,1118,296,1957]`. Tokenizer IDs and greedy continuation agree; this does not assess response quality.

Three fresh-process samples per mode on the same i7-12700 (`GOMAXPROCS=6`, GPU disabled) ran five warm twelve-token cached sessions each after model load and decoder creation. Medians were 197,916,751 ns/session decoded, 335,804,139 ns hybrid and 299,925,463 ns direct. Allocations were about 2.25 MB/11,620 decoded versus 6.34 MB/12,951–12,952 for both packed paths. A longer 20-session direct CPU profile sampled 7.65 CPU seconds: `CQMatrix.mulOne` was 3.81 seconds flat (49.80%) and 5.15 seconds cumulative (67.32%); its sampled cost includes scalar unpack and dot work. The separate decoded 20-session profile spent 55.30% flat in `SgemmNN`. These profiles include loading/setup sampling and are not wall-time shares. Raw benchmark/profile logs are under `/workspace/tmp/needle3-sustained-*.log` and `/workspace/tmp/needle3-*-cpu.prof`.

The [native CIX P1 ARM64 run](needle3-native-cq-arm64-20260927.md) passed bounded released continuation and CQ2/CQ4 dot-dispatch comparisons, and measured lower RSS with slower packed decoding. A bounded [released concurrent cancellation/retry check](needle3-native-cq-arm64-20260927.md) passed on Intel and native ARM64. Broader released prompts, long-running cancellation/retention, native RISC-V/RVV and vectorised CQ unpack/Walsh remain separate gates.
