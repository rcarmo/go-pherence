## Device operations and ownership

The new embedding operation consumes an owned flat F32 table or seed tensor and exactly represented F32 token IDs. Gather uses one output element per token/column. VJP uses one output element per vocabulary row/column and adds matching seeds in sequence order without atomics. Its dense reduction is deterministic but costs O(vocabulary * width * text rows); no released-size throughput claim is made. Limits are 1..1024 text rows, 1..16384 width, 1..65536 vocabulary and <=2^26 table elements. IDs must be explicit tape constants, integer and in range. Raw kernel callers must supply valid IDs; gather guards conversion/indexing against invalid values.

PTX and Vulkan adapters check exact extents and disjoint output ownership. PTX launch/synchronisation failures poison the operator. Vulkan uses its existing plan ownership/failure rules. Whole-tape kernel preflight covers embedding before allocation. SPIR-V contract framing now admits core `OpConvertFToU` and `OpFOrdEqual`; shader code guards range before conversion. Contract inspection remains metadata admission, not a general SPIR-V safety proof. Generated CUDA PTX and SPIR-V are included with readable source.

`training_sequence_tape.go` builds prefix `[bos_before_voice, voice, embedding(tokens), audio]` with disjoint slices/pads/sums. Shifted input is `[BOS, normalized_latents[:-1]]`; its VJP writes BOS and shifts audio-input gradients back, leaving the final target frame's conditioner derivative zero. The complete training step still adds the separate direct target gradient. Sequence backward slices voice/audio seeds and reduces embedding/BOS-before-voice parameter gradients. Empty text performs one explicit zero-seed reduction, so embedding update admission receives a complete zero gradient rather than a missing branch. Empty voice skips zero-sized tensors; speaker projection's zero-row handling remains in the previous slice.

The resident coordinator binds `flow_lm.conditioner.embed.weight`, `flow_lm.bos_emb` and `flow_lm.bos_before_voice`. Host gradient arrays stay zero. Forward does not accumulate; paired seeded backward accumulates once. When no CPU parameter branch remains, the update skips host-branch accumulation rather than admitting an empty branch map. Mock upload counters verify no parameter-gradient uploads at update. Old resident/projection/weight scopes retain their prior arithmetic; the new CLI hashes/replay identities are `*-resident-sequence-hybrid-v1`. Sequence injection/removal and cross-scope restore reject without fallback or host/replay mutation.

The new scope still copies finite host parameter values into tape metadata before resident rebinding. Per-call dense parameter-gradient/intermediate storage, forward zero-seed VJP work and redundant derivative-boundary downloads remain baseline costs. Graph caching/liveness, inter-tape device handles and reduced snapshots need separate measured work. CLI ceilings bound logical resident/tape storage separately, not total host/native allocation or released-device fit.
