# Nemotron ASR cached-convolution transpose-buffer reuse — 30 September 2026

`Encoder0Convolution.forward` now uses the second half of its owned pointwise-1 buffer for the temporary channel-major GLU transpose passed to `Encoder0ConvCache.Update`. GLU is complete before this write; the first half separately holds the depthwise result. The cache copies its retained values, while the public convolution output/residual and caller input keep independent ownership. No numerical tolerance, GPU code, or cache rollback policy changed.

Baseline: clean `347ead475286e7689984003914e6bef2a5b1f6a1`, Go 1.26.3, Linux amd64, i7-12700, `GOMAXPROCS=4`, released ASR checkpoint SHA-256 `9eebdd6590289cb3030f310858f3df93256600a800a3e8200c5993d5f967e174`. Three three-iteration `BenchmarkPCMGenerationStreamJFK` samples after the change used **1,271,751,616 B/op and 22,284 allocs/op**, compared with the preceding [point-buffer pass](nemotron-asr-convolution-point-buffer-reuse-20260930.md) at **1,285,514,176 B/op and 23,124 allocs/op**. This saves another **13,762,560 B and 840 allocations** per 11-second warm PCM-to-token request. Timings were 6.36–6.65 seconds/request after, versus 6.53–6.81 seconds before; the ranges overlap and do not establish a speedup.

The released PyTorch convolution intermediary, cache-state and cached-block fixtures passed with zero values outside their existing absolute/relative thresholds. The pinned 100-second JFK generation test passed with 1,663 decisions, 411 nonblank, no decision mismatches and zero input/tower outliers. A CPU-only AMI ES2004a 530–630-second CLI process took 56.93 seconds including WAV/checkpoint load; its independent reference WER was **88/274 = 0.321168**, with unchanged edit counts. One process does not establish a speedup.

Checks passed: cached-block failure rollback, focused `-race` parity, ASR/CLI package tests, affected `go vet`, `go build ./...` and Linux ARM64/RISC-V test-binary cross-builds. Cross-builds do not assert native execution. Local evidence is under `/workspace/tmp/nemotron-ami-es2004a-530-630/asr-conv-cache-buffer-*`; no media, weights or generated transcript is committed.
