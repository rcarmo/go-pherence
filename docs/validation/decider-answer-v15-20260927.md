# Decider v1.5 answer formatting without changing the pinned API

`FormatAnswerV15` formats supplied Choice, Score or Noul probabilities using the public answer semantics of Apache-2.0 `Mapika/decider` at `a5120cce45b9ff70964fac54ea6e8c1ac5b08c7f`. It is an explicit model-free function: callers pass probabilities and a question. The existing `Runtime.SystemOne` remains pinned to source `c4daaac28af9fea95d627015cffa2dd5a5926ee6`, where Choice and Score `confidence` mean the largest option probability. No model weights, service route or checkpoint are used by the new formatter.

For Choice, v1.5 `confidence` is the clipped `(n*p_max - 1)/(n - 1)`; uniform choices yield zero. For Score, it is the clipped `1 - expected_distance_from_modal_level / mean_uniform_distance_from_middle`. A two-level Score gives the Choice value. Both answers report the former maximum probability separately as `x_p_max`; a zero Choice/Score confidence is included explicitly in JSON. Noul reports only its existing `noul` field; it has no confidence or `x_p_max`. The formatter keeps existing probabilities, certainty, legend, score and selected option, validates the question and probability vector, and owns the probability slice so it cannot mutate caller data. It retains the Go port's existing instruction validation, including rejection of Noul without instructions; the upstream v1.3 Noul fallback is a separate request-contract change.

Synthetic tests cover upstream's published Choice and Score examples, uniform/tied distributions, a two-level Score, Noul JSON fields, invalid probabilities and the unchanged legacy maximum-probability confidence. Focused ordinary and ten race repetitions passed. These tests establish formula and response-shape compatibility for supplied probabilities, not released-model quality or temperature calibration. No held-out labels were used; a deployment that wants to expose v1.5 answers needs an explicitly versioned response selection and consumer migration plan. See the [upstream contract gap](decider-upstream-contract-gap-20260927.md) for the separate Noul and schema-first differences.
