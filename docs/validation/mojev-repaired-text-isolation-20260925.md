# MoJev branch-local text isolation probe — 2026-09-25

Upstream `MoLeMo-Lab/mojev` still points to `a74d58cd19ec573e83e8e27f9fecd837b8d830fb`; a fetch of `origin/master` showed no change to the pinned implementation. The released packed forward still leaks: `scripts/mojev_oracle_released_isolation.py` reproduced `model/mojev/testdata/released_isolation.json` byte-for-byte with the approved local checkpoint.

`model/mojev/testdata/repaired_text_isolation.json` (SHA-256 `873ad0808a9b0578a4143824cb290353fb70a6f547998dd85f780dafa41ca9d3`) records a separate **text-only experimental repair policy**. `scripts/mojev_oracle_repaired_text_isolation.py` (SHA-256 `7fe9998def69d1b14fede716d750fc527e84178ef5eeacaa1d3691edbf45ed30`) pins the same MIT source, config, 1,710,234,304-byte checkpoint and Transformers 5.17.0 Qwen3.5 implementation hashes before loading weights outside the repository. Two CPU executions produced byte-identical output. No new checkpoint was downloaded. The fixture records only synthetic token IDs, branch positions and logits.

For each candidate the Python probe forwards **only** `[state | its question | this candidate]` through a fresh encoder call. The branch keeps each token's absolute position from the original packed row. The 4D tree mask gives full attention within-node visibility and ancestor visibility. The recurrent linear-attention path remains causal inside each node, but sees no sibling tokens because they are absent from the branch. This differs from the released packed model's linear-state history, so repaired logits are expected to differ. It also differs from a fully bidirectional linear-attention implementation; the checkpoint's training behaviour under this policy has not been evaluated.

For the 12-token two-question fixture, changing candidate `a1` at position 7 leaves `a0` and both question B logits exactly unchanged; `a1` changes from `0.2599636912` to `0.2450570017`. Changing question B's first token at position 8 leaves both question A logits unchanged and moves both question B logits. The released packed forward changed question B logits by about `0.21` and `0.18` for the candidate substitution. These are exact observations of three synthetic inputs, not a general independence proof or a quality measurement.

The Go `ScoreBranchLocalText` boundary constructs owned per-candidate tokens and absolute positions and calls an injected encoder once per candidate. It applies the existing head to each supplied hidden path. Tests cover branch geometry, caller ownership, transactional failures, concurrent use and synthetic sibling isolation. No Go encoder has been wired to the boundary, and an arbitrary injected callback could still reuse sibling state. Native Go layer/hidden/logit parity, longer nodes, padding, multimodal inputs, calibration, held-out quality, memory and service behaviour remain untested. `ReadConfig.RuntimeReady=false`.
