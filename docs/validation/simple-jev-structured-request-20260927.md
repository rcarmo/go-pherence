# Simple-JEV structured-state request subset

`DecodeStructuredStateRequest` admits a bounded JSON object or array state with the existing text-only Choice, Score and Noul question subset. It returns the state's canonical JSON separately as `StateJSON`; it does not broaden `DecodeTextStateRequest`, render a prompt, invoke a tokenizer/model, or expose HTTP.

It contains request objects and canonical state only, no prompt text, model logits or weights.

Go preserves question and criterion order, nullable text and option flags on object, array, empty-object and empty-array states. It rejects missing/null/numeric/boolean state, messages/media, duplicate members, malformed UTF-8, trailing data, oversized requests and state over 64 KiB. `CanonicalStructuredState` retains its independently tested strict subset: signed 64-bit integer numbers only, 32-level depth limit and rejection of ambiguous Unicode cases. Those restrictions are narrower than upstream Python. The returned request owns its data after the reader buffer is changed, and reader errors return no partial request. The existing text-state decoder still rejects structured state.

Focused/package ordinary and race repetitions passed. This is a model-free wire-subset and state-canonicalisation result. No upstream v1 prompt, concrete model adapter, HTTP path, released-model parity, calibration or quality result follows from it.
